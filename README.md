# 串口温湿度采集工具

C# WinForm 开发的串口温湿度采集桌面工具，配合 NodeMCU + DHT11 传感器使用，实现温湿度数据的实时采集与显示。

## 硬件连接
- **主控**：NodeMCU (ESP8266)
- **传感器**：DHT11 温湿度传感器（数据引脚接 D5/GPIO14）
- **连接方式**：USB 转串口连接 PC

## 功能特性
- 串口参数可视化配置（端口号、波特率、数据位、校验位、停止位）
- 按行读取传感器数据，利用换行符自然分隔数据帧，无需手动处理粘包/半包
- 数据容错：过滤 ERROR 帧、业务范围校验（温度 -20~60℃，湿度 0~100%）
- 上电初始化时序处理：延时等待传感器就绪，双重清空缓冲区，避免启动乱码
- 断线检测与自动重连（捕获 ErrorReceived 事件，最多重连 5 次，间隔 2 秒）
- 跨线程 UI 更新：使用 BeginInvoke 异步委托，界面不卡顿
- 智能日志滚动：用户手动翻阅历史时暂停自动滚动，查看完毕自动跟随
- 日志输出简洁，直显温湿度数值，无冗余调试信息

## 通信策略
- 传感器为**主动上报**模式，上位机仅接收，不发指令
- 采用 `SerialPort.ReadLine()` 按行读取，利用 NodeMCU `Serial.println()` 自带的换行符作为帧分隔
- 读取超时设置为 500ms，超时后退出等待，避免阻塞 UI 线程

## 运行方法
1. 用 Visual Studio 打开 `串口温湿度.slnx`
2. 将烧录代码刷入 NodeMCU 开发板
3. 编译运行上位机，选择串口号（默认 9600 波特率），点击“打开串口”
4. 程序等待传感器初始化完成后，自动显示温湿度数据

## 技术栈
C# | WinForm | .NET Framework 4.8 | SerialPort | 多线程 | 串口通信

## 注意事项
- DHT11 传感器精度有限（湿度 ±5%RH，温度 ±2℃），数据存在正常波动
- NodeMCU 运行时会发热，可能导致温度读数缓慢上升
